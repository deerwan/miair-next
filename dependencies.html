组件类型用途说明
FastAPI / UvicornPython 框架现代异步后端 REST API 与 WebSocket 实时状态推送
Vue 3 / Vite / Naive UI前端技术栈响应式轻量 Web 管理后台，支持亮色/暗色三态主题
ffmpeg系统依赖音频实时转码与流式处理（支持 WAV 与 MP3 格式输出）

libportaudio2系统依赖底层跨平台音频 I/O 支持
libatomic1系统依赖Spotify Soloist 二进制动态依赖库
dnsutils系统依赖网络环境与 DNS 解析探测诊断
Shairport Sync 5.5.2 / NQPTP 1.2.8原生接收器标准镜像内置的 AirPlay 2 接收与 PTP 时钟；Shairport 带定时 PCM 扩展和独立元数据 FIFO，NQPTP 对应源码随镜像分发
